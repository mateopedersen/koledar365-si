# Share-button icon sources

The share panel uses the platforms' own distributed logo files. These marks identify destinations; Koledar365 has no affiliation with those platforms. The logos are not recolored, redrawn or combined with the Koledar365 identity. The surrounding cards belong to Koledar365.

| Local asset | Official source |
| --- | --- |
| `public/social/whatsapp.svg` | [Meta WhatsApp Brand Resource Center](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/) — 2026 digital green glyph from its logo pack |
| `public/social/telegram.svg` | [Telegram press logo pack](https://telegram.org/press) — `Logo.svg` |
| `public/social/facebook.png` | [Meta Facebook Logo pack](https://www.meta.com/brand/resources/facebook/logo/) — primary logo |
| `public/social/x.png` | [X official web app](https://x.com/) — its 1024 px Apple touch icon |
| `public/social/bluesky.svg` | [Bluesky official brand assets](https://bsky.social/about/support/icons) — blue butterfly SVG |
| `public/social/linkedin.png` | [LinkedIn brand downloads](https://brand.linkedin.com/downloads) — official `[in]` icon |
| `public/social/pinterest.png` | [Pinterest official website](https://business.pinterest.com/brand-guidelines/) — its red high resolution site badge |
| `public/social/mail.svg` | Koledar365 generic email drawing, not a platform logo |

Review the linked platform guidelines when refreshing the assets.
