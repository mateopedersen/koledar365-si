This adapter publishes Rails-rendered HTML on Cloudflare Pages Free. Ruby 4.0.7/Rails 8.1.4 remain the build/content/data stack. Browser calculations and personalized PDF composition execute the same Ruby service code using the official ruby.wasm 4.0 browser port (runtime package 2.10.1, Ruby 4.0.0). The small Pages Functions proxy weather only. No R2, Containers, VPS, database binding or paid resource is enabled.

Private entries/photos stay in browser memory/localStorage; PDF/WebP are generated there. Public standard calendars are pre-generated in Ruby and verified before publication. Browser WASM downloads are lazy and self-hosted, split below Pages' per-file limit, checked by SHA-256. The browser runtime intentionally uses the four bundled TrueType fonts; CFF/OpenType font imports are not supported. The copied TTFunk CFF loader omits an unavailable BigDecimal dependency; CFF code is never invoked. Ruby calendar/PDF service sources are copied verbatim.

The original server Rails/Docker/PostgreSQL implementation is preserved in Git and can still run independently. The free deployment must not be represented as an always-running Rails server or a hosted PostgreSQL database. GitHub authenticated source editing and reviewed release builds replace the deployed Rails-only editorial login. No admin password or private message database is included in static output.
