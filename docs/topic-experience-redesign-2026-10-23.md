## Design and interaction

- Avenir site typography; Slovenian blue/red/white structural palette. Natural colors on plants and astronomical objects help identify them.
- Body, filter and reference text enlarged. Event titles and dates have a stronger weight and hierarchy. Specialist content targets 17–19 px minimum; captions and secondary labels are at least 16 px.
- Responsive cards and readable comparison rows on phones, without hiding table meaning. Large calendar day cells and 48 px action controls.
- Education quick categories use the existing filter form and existing export selection, with no parallel date logic.
- Preparation lists are isolated by canonical pathname and survive reloads. Blocked/full storage has an explicit in-page message and memory-only fallback.
- Original SVG files generated by `script/build_topic_illustrations.py`. All vectors have a title/description and a meaningful HTML alt text.
- Garden photographs and the central photo license page remain unchanged; no per-photo license clutter was introduced.

## Numeric date presentation follow-up

The requested compact interface style (`31.10.`, `31.10.2026`) is applied to rendered HTML and dynamically inserted visible text, with calendar-validity checks. Written month names, ISO values, structured scripts, editable notes, downloadable calendar source data and the existing PDF/WebP collection are preserved. This is an interface choice; it does not change Slovenian date rules or the underlying dates. The short home holiday date cannot wrap internally.

A shared 20-case fixture checks Ruby/JavaScript parity, leap dates, invalid dates, punctuation, Unicode spacing, ISO and version strings. A final static formatting pass covers content added by SEO builders; a mandatory audit checks every canonical sitemap page for remaining valid spaced numeric dates.
